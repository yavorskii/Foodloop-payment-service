# FoodLoop Payment Service

This is the Payment Microservice for the FoodLoop project, built with Clean Architecture, Domain-Driven Design (DDD), and Spring Boot.

## Features
- Payment processing via Stripe / LiqPay
- Refunds
- Asynchronous Domain Events (Kafka) using Transactional Outbox Pattern
- Stripe Webhook integration for payment status updates
